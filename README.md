# 워띵클라우드 (Word-Thing Cloud)

강의·행사·수업에서 참가자의 생각을 모으는 워드클라우드입니다.

## 현재 개발 상태

화면과 API, Supabase 전용 `wordthing` 스키마, Vercel 함수 구성이 준비 중입니다. 운영 환경에서의 데이터베이스 연결, 권한, 실시간 알림 및 부하 검증을 마치기 전까지는 배포 완료로 간주하지 않습니다. 기존 포토팀의 `phototeam` 스키마는 변경 대상이 아닙니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다. Node.js 24 이상을 권장합니다.

```powershell
npm ci
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 로컬 개발에서는 SQLite를 사용하며 관리자 진입 코드와 개발용 비밀번호는 `tting`입니다. SQLite는 개발과 테스트 용도이며 Vercel 운영 저장소로 사용할 수 없습니다.

```powershell
npm test
```

테스트는 임시 SQLite를 사용하므로 Supabase·Realtime·Vercel 검증을 대체하지 않습니다.

## 운영 구성

- Supabase `creodedulab-shared` 프로젝트의 별도 `wordthing` 스키마에 데이터를 보관합니다.
- 서버 전용 데이터베이스 로그인은 워띵클라우드에만 필요한 권한을 가져야 합니다. 서비스 비밀키나 데이터베이스 비밀번호는 브라우저와 공개 저장소에 넣지 않습니다.
- `DATABASE_URL`, `ADMIN_PASSWORD_HASH`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`는 운영 환경에서 설정합니다. 관리자 비밀번호는 공개된 개발용 비밀번호와 다른 값이어야 합니다.
- 실시간 알림에는 데이터나 개인정보를 넣지 않고, 클라이언트가 권한을 확인하는 API를 통해 다시 조회합니다. 연결 장애 시 폴링으로 전환합니다.
- 동시 접속 목표는 200명입니다. Supabase Realtime 무료 연결 한도는 포토팀과 공유하므로 실제 200명 이용 가능 여부는 부하 시험이 필요합니다.

관리자가 방을 삭제하기 전까지 보관합니다. 자동 삭제 기간은 아직 정하지 않았고 자동 삭제 기능도 구현하지 않았습니다. 퇴출은 같은 방의 기존 닉네임 재접속을 막지만 다른 닉네임으로 새로 가입하는 것까지 식별하지 못합니다.

비밀번호, 세션 정보 및 실제 개인정보가 포함된 파일을 커밋하지 마세요.
